# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted contributions: the contributor owns the work, FINOS's files stay FINOS's, the schema is written by the converter, a condition is stated only as the CDM states it, and no mapping is guessed.
* [Licence and attribution](license-and-attribution.md) - Which licence applies where: the schema project under Apache 2.0, FINOS's files under the Community Specification License 1.0, and the CDM's descriptions in the schema carried with the attribution that licence asks for.
* [Security policy](security-policy.md) - How to report a vulnerability, what this repository releases, what executes here and what holds each surface, as `.github/SECURITY.md` states.
