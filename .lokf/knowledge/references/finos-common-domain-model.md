# FINOS Common Domain Model

The CDM is FINOS's model of financial products, trades and the events in their lifecycle, written in the Rosetta language. This repository is a fork of FINOS's repository and holds its tree at the release `upstream/pin.yaml` names: 8.0.0-dev.13, commit `dafe7bab2c01`, of 27 October 2026.[^pin.yaml]

FINOS licenses the CDM's specifications under the Community Specification License 1.0, which allows a derivative work that names the material, its version and its source.[^license.md] NOTICE gives that attribution for the schema.[^notice]
