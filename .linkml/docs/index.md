# common-domain-model

A LinkML schema of the [Common Domain Model](https://cdm.finos.org/) (CDM) that FINOS publishes, at release 8.0.0-dev.13, written from the CDM's own Rosetta files.

- [How the schema reads the CDM](about.md): what each Rosetta construct becomes, what LinkML cannot state, and how a CDM document is read.
- [The schema](https://github.com/lmodel/common-domain-model/tree/master/.linkml/src/common_domain_model/schema), one module per Rosetta namespace.
